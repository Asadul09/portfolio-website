# React Portfolio

A modern, responsive, frontend-only personal portfolio built with **React, Vite, Tailwind CSS, and Lucide Icons**. It showcases my professional profile, technical skills, projects, and experience through a clean and interactive user interface.

🌐 **Live Portfolio:** [https://portfolio-website-pi-five-83.vercel.app/](https://portfolio-website-pi-five-83.vercel.app/)

## 🚀 Tech Stack

- **Frontend:** React.js, Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Deployment:** Vercel

## ✨ Features

- Responsive and modern portfolio design
- Professional profile and introduction
- Technical skills and expertise
- Project showcase with descriptions and links
- Work experience and education sections
- Contact form with email app integration
- Fast performance and optimized frontend build

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/Asadul09/portfolio-website.git
cd portfolio-website
```

Install frontend dependencies:

```bash
npm run install:frontend
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite (usually `http://localhost:5173/`).

Alternatively, run the frontend directly:

```bash
cd frontend
npm install
npm run dev
```

## 🛠️ Build & Lint

From the project root:

```bash
npm run build
npm run lint
```

## ⚙️ Customization

- Update personal information, projects, and technical skills in `frontend/src/data/portfolio.js`.
- Modify components and UI layouts in `frontend/src/components/` and `frontend/src/`.
- The contact form opens the visitor's default email application with a prepared message. Visitors must complete sending through their email app.

**Note:** This is a frontend-only application. It does not require a backend or database, and contact messages are not stored or sent directly by the website.
