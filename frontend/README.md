# Frontend

This is the complete React portfolio application. It runs with Vite and uses local portfolio data from `src/data/portfolio.js`; there is no backend or database.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build and lint

```bash
npm run build
npm run lint
```

The contact form prepares a message in the visitor's email app. It does not store or send submissions from the website.
